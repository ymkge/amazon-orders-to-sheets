# Amazon Orders to Google Sheets

Amazon.co.jp の注文履歴から指定した年月の注文データを抽出し、Google スプレッドシートへ自動で保存・追記する Chrome 拡張機能（Manifest V3）です。

---

## 主な機能

- 🗓️ **年月指定で抽出**: ドロップダウンから対象年月（例: `2026年5月`）を選択するだけで、該当する注文件を自動抽出。
- 🔄 **スマートな走査制御**: Amazon注文履歴の降順特性を活かし、指定月より古い注文に到達した時点で自動終了。
- 🤖 **CAPTCHA・レートリミット対策**: 次ページへの遷移ごとに 1.5 〜 2.5 秒のランダムウェイトを自動挿入。
- 🚫 **重複防止ロジック**: スプレッドシート側で「注文番号 + 商品名」を識別し、過去に同期済みの注文はスキップ。
- 📊 **リアルタイム進捗表示**: 現在何ページ目を解析中か、抽出件数、待機時間、書き込み結果をPopup上にわかりやすく表示。
- 🔒 **シンプル＆安全なGAS連携**: 認証キー管理を不要にするため、Google Apps Script (GAS) の Web API エンドポイント（`doPost`）経由で安全にデータ投入。

## セットアップ手順

### ステップ 1: Google スプレッドシート & GAS の準備

1. [Google スプレッドシート](https://sheets.new) を新規作成します。
2. 上部メニューの **「拡張機能」** > **「Apps Script」** をクリックします。
3. エディタに表示されているコードをすべて削除し、本リポジトリの [src/gas/Code.gs](src/gas/Code.gs) の内容をそのまま貼り付けて保存します（`Ctrl + S` または `Cmd + S`）。
4. 画面右上の **「デプロイ」** ボタンをクリックし、**「新しいデプロイ」** を選択します。
5. 左上の歯車アイコン（種類の選択）をクリックし、**「ウェブアプリ」** を選択します。
6. 設定を以下のように入力します：
   - **説明**: 任意（例: `Amazon注文連携API`）
   - **次のユーザーとして実行**: `自分`（デフォルト）
   - **アクセスできるユーザー**: `全員`（※拡張機能からのリクエストを受け付けるために必須です）
7. **「デプロイ」** ボタンをクリックし、初回のみ「アクセスを承認」画面が表示されたら承認します。
8. 発行された **「ウェブアプリの URL」**（`https://script.google.com/macros/s/.../exec`）をコピーします。

---

### ステップ 2: Chrome 拡張機能のインストール

1. Google Chrome を起動し、アドレスバーに `chrome://extensions/` と入力して拡張機能管理画面を開きます。
2. 右上の **「デベロッパー モード」** のトグルスイッチを **ON** にします。
3. 左上に表示される **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. 本プロジェクトのルートフォルダ（`manifest.json` が存在するフォルダ）を選択します。
5. ツールバーのパズルピースアイコンから「Amazon Orders to Sheets」をピン留めすると便利です。

---

### ステップ 3: 拡張機能の設定（GAS URL の登録）

1. Chromeツールバーの拡張機能アイコンをクリックし、Popup右上の歯車アイコン（⚙️）を押すか、拡張機能管理画面の「詳細」>「拡張機能のオプション」を開きます。
2. **「GAS Web API URL」** 欄に、ステップ 1 でコピーしたウェブアプリのURLを貼り付けます。
3. **「接続テスト」** ボタンをクリックして「✅ 接続成功」と表示されることを確認します。
4. **「設定を保存」** をクリックします。

## 使い方・実行フロー

1. 事前にブラウザで [Amazon.co.jp](https://www.amazon.co.jp/) にログインしておきます。
2. 拡張機能アイコンをクリックして Popup を開きます。
3. **「対象年月を選択」** から取得したい月（例: `2026年 5月`）を選択します。
4. **「📊 スプレッドシートへ連携」** ボタンをクリックします。
5. 拡張機能が自動で以下の処理を行います：
   - 対象年の注文履歴ページ（`timeFilter=year-YYYY`）へナビゲート。
   - 注文番号、注文日、商品名、単価、数量、合計金額、商品URLをパース。
   - 1.5〜2.5秒のウェイトを挟みながら「次へ」ボタンを巡回。
   - 対象月より古い注文が出現した時点で探索を安全に終了。
   - 取得した注文データを Google Apps Script へ一括送信。
6. スプレッドシートの「Amazon注文履歴」シートに自動でヘッダーと注文データが追記されます。

## スプレッドシートのカラム構成

| カラム名 | 説明 | 例 |
| :--- | :--- | :--- |
| **注文日** | 注文確定日（`YYYY-MM-DD`） | `2026-05-12` |
| **注文番号** | Amazonの注文番号 | `503-1234567-8901234` |
| **商品名** | 購入した商品タイトル | `サンプルプログラミング書籍` |
| **商品単価** | 商品単価（数値） | `2100` |
| **数量** | 購入数量 | `1` |
| **注文合計** | 注文全体の請求合計額 | `2100` |
| **商品URL** | 商品ページURL（ASIN正規化済み） | `https://www.amazon.co.jp/dp/B08ABCDEFG` |
| **登録日時** | スプレッドシートへの追記日時 | `2026-09-20 23:45:00` |

## トラブルシューティング

- **「GAS Web APIのURLが未設定です」と表示される**
  - Popup右上またはオプション画面で、ウェブアプリURLが正しく保存されているか確認してください。
- **「接続テスト」でエラーになる**
  - GASデプロイ設定の「アクセスできるユーザー」が **「全員」** になっているか確認してください。「自分のみ」になっているとブラウザ拡張機能からのアクセスが拒否されます。
  - コード変更後にデプロイを更新する場合は、「新しいデプロイ」またはバージョンを「新バージョン」として再デプロイする必要があります。
- **「Amazon注文履歴ページとの通信に失敗しました」**
  - Amazonにログインしているか確認し、一度注文履歴ページを開いてから再度連携ボタンを押してください。
- **重複して登録されてしまう**
  - スプレッドシート側で「注文番号」と「商品名」をキーに判定しています。スプレッドシートのB列（注文番号）・C列（商品名）が書き換えられていないか確認してください。
